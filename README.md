# Hotel Management System

Консольное MVP-приложение для управления отелем (лабораторная работа №2, вариант 18).

## Возможности
- добавление и просмотр гостиничных номеров;
- регистрация гостей;
- создание бронирований с проверкой вместимости и пересечения дат;
- расчёт количества ночей, стоимости проживания и фиксированного сбора за бронь;
- просмотр статистики и экспорт отчёта в DOCX;
- хранение номеров, гостей и бронирований в SQLite.

## Архитектура
Пакет `hotel` содержит ровно три рабочих модуля:
- `models.py` — сущности, абстрактный базовый класс, наследование, managed-атрибуты и dunder-методы;
- `database.py` — схема SQLite и операции хранения;
- `services.py` — прикладная логика, экспорт и консольное меню.

## Правила расчёта
- количество ночей = дата выезда − дата заезда;
- стоимость проживания = количество ночей × цена номера за ночь;
- сбор за бронирование = 500 руб.;
- итог = стоимость проживания + сбор за бронирование.
Тарифы и сбор являются учебными демонстрационными допущениями, а не реальными тарифами отеля.

## Запуск локально
Требуется Python 3.12 или новее.

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
python main.py
```

## Запуск через Docker
Установите и запустите Docker Desktop (или Docker Engine), затем из корня проекта:

```bash
docker compose up --build
```

Остановить приложение: `Ctrl+C`. Повторно запустить созданный контейнер в интерактивном режиме:

```bash
docker start -ai hotel_management_app
```

SQLite-файл хранится в Docker volume `hotel_data`, смонтированном в `/app/data`. Поэтому данные сохраняются после остановки и пересоздания контейнера. Чтобы удалить и контейнер, и данные, используйте `docker compose down -v` (ОСТОРОЖНО: команда удаляет базу).

## Тестирование

```bash
pytest -v
```

## Краткая справка
1. Сначала добавьте номер.
2. Зарегистрируйте гостя.
3. Создайте бронирование, указав ID гостя и номера, даты в формате `ГГГГ-ММ-ДД` и число гостей.
4. Посмотрите список бронирований или статистику.
5. Экспортируйте DOCX-отчёт.

Типы номеров: `Стандарт`, `Комфорт`, `Люкс`.
